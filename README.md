# Autonomous-Grass-Cutting-Rover
A smart, self-navigating utility rover built with an ATmega328P, HC-SR04 sensor, and L298N motor driver. It features dynamic obstacle avoidance, a safety-interlocked grass cutter, and an automated 12V weedicide pump.


This repository contains the firmware and hardware architecture for a Smart Autonomous Grass Cutting & Weedicide Rover. 

Built as a prototype for automated terrain maintenance, the robot operates in a continuous feedback loop of sensing, deciding, and acting. 

It uses ultrasonic distance sensing to avoid hazards, a relay-switched high-speed cutting motor that includes a forward-motion safety lock, and an independent 12V fluid pump for chemical distribution. 

This project showcases practical applications of embedded systems design, sensor fusion, motor control logic, and power rail management.
